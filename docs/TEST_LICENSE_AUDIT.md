# Licencias de instrumentos

El único payload Android existente es AMAS-A y su manifest/índice lo clasifica como restringido. La web lo muestra como metadato de revisión y no incorpora preguntas, opciones, escalas ni rangos en `src`, `public` o bundle. Para revisión profesional se requiere backend protegido, allowlist, Custom Claim, expiración y auditoría en `testProfessionalReviews`.

Las entradas de índice sin payload se reportan como no ejecutables y no aparecen como instrumentos disponibles al usuario público.
