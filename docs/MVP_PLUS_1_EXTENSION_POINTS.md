# Puntos de extensión MVP+1

Los metadatos de test admiten `creatorId`, `ownerType`, `organizationId`, `visibility`, `status`, `access`, `price`, `currency`, `license`, `latestVersion`, `publishedAt` y `approvalStatus`. El modelo separa versiones, catálogo público, entitlements y perfiles para permitir constructor de tests, marketplace, instituciones y reportes agregados sin exponer resultados individuales.
